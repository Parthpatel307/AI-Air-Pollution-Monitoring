# AI Air Pollution Monitoring

Full-stack air quality monitoring platform with a FastAPI backend, AI/ML services, and a React frontend.

## Repository layout

- `Vaibhav/backend`: FastAPI API and domain services
- `Parth/ai-ml`: forecasting, source detection, vision, and Gemini modules
- `Tirth/frontend`: Vite + React client
- `docs`: architecture, API, data, security, and deployment notes

Each team area contains its own README and dependency file where applicable.
